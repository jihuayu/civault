- 概念：带开口的圆形 C 围合中心一点，表达受保护的密钥、受控访问与平静秩序。
- 色彩：以近黑色 `#171717` 为目标色；使用生成的透明 PNG 原图。当前资产是位图，不是矢量母版。

- 禁止：渐变、投影、发光、描边、彩色填充或装饰纹理。
